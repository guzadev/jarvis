JARVIS PARA WINDOWS X64 — 0.1.3 (BETA)

Descarga: https://github.com/guzadev/jarvis/releases/tag/v0.1.3
Usá Jarvis-Windows.exe para descargar y abrir el instalador completo.
Alternativa manual: mantené Jarvis-Windows-Instalador.exe y TODAS las partes
Jarvis-Windows-Instalador-*.bin en la misma carpeta y abrí el EXE.

El paquete incluye Python, dependencias, Whisper Small, Qwen3-TTS 1.7B,
perfil de voz y Ollama/Qwen3:8b. No necesitás instalar Python ni Node.
La síntesis elegida requiere GPU NVIDIA compatible con CUDA. Probado en RTX3060.
Reservá al menos40GB libres para descarga e instalación. Windows x64 solamente.
No se afirma compatibilidad con todos los equipos; es una versión beta.

PRIMER INICIO
1. Pegá TU clave OpenAI en el formulario. Se guarda cifrada en tu usuario Windows.
2. Abrí Jarvis. La escucha está APAGADA por defecto.
3. Pulsá ESCUCHA APAGADA · ACTIVAR; decí Jarvis para iniciar la conversación.
4. Apagar escucha corta micrófono y sesión. Cerrar con X sale de la app.
   Ocultar/minimizar o cambiar de ventana también suspende la escucha.
5. Para Claude Code y APIs propias, consultá las guías del repositorio.

OpenAI: https://github.com/guzadev/jarvis/blob/main/docs/CLAVE-OPENAI.md
Claude: https://github.com/guzadev/jarvis/blob/main/docs/CONECTAR-CLAUDE.md
APIs: https://github.com/guzadev/jarvis/blob/main/docs/AGREGAR-APIS.md

Cada persona usa sus propias cuentas y saldo. OpenAI es de pago por uso;
Claude depende del acceso contratado en su cuenta. La voz se genera en la PC.
No se incluyen claves, cuentas, memoria ni proyectos del desarrollador.
Los trabajos nuevos se guardan en Documentos/Jarvis/General.
