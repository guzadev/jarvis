# Seguridad y credenciales

No publiques claves, tokens, códigos de inicio de sesión ni bases de datos personales en issues o pull requests. Los ejemplos del repositorio no contienen claves funcionales.

Las claves de la aplicación se configuran en la PC y se protegen para el usuario de Windows. Si compartiste una clave por accidente, revocala desde el proveedor y configurá una nueva en tu instalación. No hace falta enviar una clave al mantenedor para informar un error.

Al reportar un fallo, indicá versión, Windows, hardware, mensaje de error y pasos para reproducirlo. Revisá cualquier captura o registro antes de adjuntarlo.
